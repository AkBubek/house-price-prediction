# 🏠 House Price Prediction

Проект по предсказанию цен на жильё с использованием методов машинного обучения.

## 📌 О проекте
Цель — построить модель, которая предсказывает стоимость дома на основе его характеристик (количество комнат, возраст здания, расстояние до центра занятости и др.). Использован классический датасет Boston Housing.

## 📊 Данные
- 506 записей, 13 признаков + целевая переменная (цена)
- Пропущенных значений нет
- Признаки: уровень преступности в районе, доля жилых земель, число комнат, возраст здания, расстояние до центра занятости, налоговая ставка и др.

## 🛠 Что сделано
- Разведочный анализ данных (EDA): распределение цен, проверка пропусков
- Разделение данных на train/test (80/20)
- Обучены и сравнены две модели:
  - Linear Regression
  - Random Forest Regressor
- Анализ важности признаков
- Визуализация: реальные vs предсказанные значения
